01 · Representation learning

Classification gets the answer. SupCon shapes the space.

Cross-entropy rewards the model for choosing the correct label. That can produce accurate decision boundaries without requiring samples from the same person to sit tightly together. Supervised contrastive learning optimizes the geometry we actually use at inference time.

Cross-entropy baseline

Correct, but loosely arranged

The classifier learns which side of a boundary each face belongs on. Embeddings from neighboring identities can still be diffuse or close together.

Selected approach

Compact and deliberately separated

Each face acts as an anchor. Other augmented images of the same celebrity are positives; every different identity is a negative. The loss pulls positives closer and pushes negatives away.

02 · The training recipe

A face-specialized foundation, carefully fine-tuned.

The backbone starts with facial features learned from VGGFace2. Training then adapts that representation to the celebrity dataset while preserving a normalized metric space.

  1. 01

    Detect and align

    A face detector isolates one clear face. Every crop receives the same FaceNet pixel standardization used in training and production.

  2. 02

    Create two views

    Independent crops, flips, color changes, blur, and small geometric variations teach the model to ignore pose and lighting noise.

  3. 03

    Learn normalized embeddings

    An InceptionResnetV1 backbone pretrained on VGGFace2 feeds a projection head. L2 normalization places every embedding on the same unit hypersphere.

  4. 04

    Balance every batch

    Each batch contains 16 identities with 4 samples per identity and two augmented views, ensuring every anchor has meaningful positives and negatives.

  5. 05

    Select by geometry

    Checkpoints are chosen using the validation separation ratio—not training accuracy alone—so compact clusters and distance from neighboring classes drive selection.

ℒ
Supervised contrastive objective

For each anchor, the loss rewards high similarity to every same-class positive and penalizes similarity to all other faces in the batch. A temperature of 0.10 controls how strongly the model focuses on difficult neighbors.

03 · Evidence, not intuition

SupCon won on both geometry and validation accuracy.

The comparison used a stratified validation split and the same pretrained backbone. The winning setup ran for 20 epochs before a final production refit on all available images.

04 · From selfie to match

Three views become one temporary prototype.

At inference time, the system applies the same detection, cropping, standardization, and normalization used during training. It averages three selfie embeddings and normalizes the result into one more stable user prototype.
